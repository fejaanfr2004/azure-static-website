
# Azure Static Website Hosting

## Project Overview

This project demonstrates hosting a static website using Microsoft Azure Storage Account Static Website feature.

## Technologies Used

- HTML
- CSS
- JavaScript
- Microsoft Azure
- Azure Storage Account

## Features

- Cloud Hosted Website
- High Availability
- Scalable Architecture
- Secure Storage
